= Changelog

== [Unreleased]

=== Added

- dtmt: split `build` into `build` and `package`
- dtmt: implement deploying built bundles
- dtmm: indicate when a deployment is necessary
- dtmm: check for Steam game update before deployment
- dtmm: remove unused bundles from previous deployment
- dtmm: show dialog for critical errors
- dtmm: check mod order before deployment
- dtmt: add mod dependencies to config
- dtmm: match mods to Nexus and check for updates
- dtmt: add utility to migrate mod projects
- dtmm: reset dtkit-patch installations
- sdk: implement decompiling Lua files
- dtmm: fetch cover image for Nexus mods
- dtmm: fetch file version for Nexus mods
- dtmm: handle `nxm://` URIs via IPC and import the corresponding mod
- dtmm: Add button to open mod on nexusmods.com
- dtmt: Implement commands to list bundles and contents
- dtmt: Implement command to search for files
- sdk: decompile textures, including streamed mipmaps
- sdk: compile textures from `.texture` definitions and DDS files
- sdk: store non-streamed textures as external data files, matching the game
- dtmm: deploy a mod's external data files (streamed texture mipmaps, etc.)
- dtmt: inject a `BootStateLoadMods` step into Darktide's boot state list, so
  mods load on the current Darktide build
- dtmm: provide DMF-free `new_mod`/`get_mod` helpers so mods no longer need to
  depend on the Mod Framework
- dtmm: add headless `--deploy` and `--reset` flags for scripted deployments
- dtmm: back up every game file a deployment overwrites and restore it on reset

=== Fixed

- all: force unix path separators for engine values
- dtmt: fix extracing files with non-flattened file names
- oodle: fix static linking
- sdk: write the game's current 24-byte Lua file header instead of the old
  12-byte one, which made the game crash with a UTF-8 error on startup
- dtmm: quote mod versions in the generated `mod_data.lua`, so SemVer strings
  like `0.1.0` are not parsed as malformed Lua numbers
- sdk: sort a bundle's file entries by `(type, name)` when writing, since the
  engine binary-searches them. Unsorted entries crashed the game with a UTF-8
  error once a bundle contained more than one file
- sdk: preserve the NUL-padded length a bundle declares for an external data
  file name, instead of writing only the trimmed string and shifting every
  following file entry
- sdk: pad newly written external data file names to the engine's slot size.
  Darktide stores a `data/xx/<hash>` name as 24 bytes of text in a 30-byte
  NUL-padded slot; writing 24 bytes corrupted the next file entry and crashed
  the game with a UTF-8 error when a bundle had two or more external files
- dtmm: reject external data file names that would escape the game's `bundle`
  directory
